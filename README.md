# AWS Resource Provisioning Automation using Boto3

## Project Overview

This project automates AWS resource provisioning using Python and the Boto3 SDK. Instead of manually creating AWS resources through the AWS Management Console, the script automatically creates and manages cloud infrastructure.

## Objective

To automate AWS infrastructure provisioning using Python scripts and Boto3 without performing manual configuration in the AWS Console.

## Services Used

* AWS IAM (Identity and Access Management)
* Amazon S3 (Simple Storage Service)
* Amazon EC2 (Elastic Compute Cloud)
* Boto3 (AWS SDK for Python)
* AWS CloudShell

## Features

* Creates an IAM User automatically
* Creates an S3 Bucket automatically
* Launches an EC2 Instance automatically
* Demonstrates Infrastructure Automation using Python

## Architecture Flow

CloudShell → Python Script (Boto3) → AWS APIs → IAM, S3, EC2

## Technologies Used

* Python
* AWS CloudShell
* Boto3
* AWS IAM
* Amazon S3
* Amazon EC2

## Output

The script successfully:

1. Created an IAM User
2. Created an S3 Bucket
3. Launched an EC2 Instance

## Benefits

* Reduces manual effort
* Saves time
* Ensures consistent infrastructure deployment
* Demonstrates Infrastructure as Code (IaC) concepts
